# ワールドレポートの記録形式（試案 v0.1）

「その場所の情報」と「その日に自分が感じたこと」を、混ぜずに一緒に残すための小さな約束です。VRChatの公式規格ではなく、VRMのような既存の標準との互換性もありません。まず個人の記録から始め、使いながら項目を見直します。

## なぜ用意したか

自由な文章だけでもレポートは書けます。ただ、記録が増えると「どこだったか」「いつ、どの環境で行ったか」を揃えて探すのが難しくなります。そこで、ワールドURLや訪問条件を共通の欄に分け、感想は箇条書きで自由に残します。

同じワールドでも、更新や訪問時の条件で体験は変わります。ワールドIDは場所の識別、レポートIDは一回の記録の識別に使います。再訪を上書きする必要はありません。

将来はSQLで条件を絞り、文章検索やAIによる自然文の検索を組み合わせたいと考えています。**現在のツールにはAI検索・ベクトル検索・LoRA学習は実装していません。** 現在できるのはSQLiteへの蓄積と文字列検索、素材の受け渡し、記事の編集・投稿です。

## 使い方

1. [テンプレート](../templates/world-report-v0.1.md) をコピーする。アプリなしでも使えます。
2. URL・名前・作者などの確認済みの基本情報を書く。
3. 訪問日と実際に使った環境を書く。「PCで訪問した」と「PCのみに対応している」は別の情報です。
4. 7つの感想欄から書けるものを箇条書きにする。全欄を埋める必要はありません。
5. 写真と短い説明を添える。記事化しても元のメモは残します。
6. 記事を自分で読み直してから公開する。

たとえば、仮の記入例なら「窓際に座って雨音を聞いた」「一人で落ち着きたいときによさそう」で十分です。作者が「軽量」と説明していても、自分の端末で確認していなければ快適だったとは書きません。

## 項目とアプリ内データの対応

| 内容 | 保存項目 | 扱い |
| --- | --- | --- |
| ワールドID・URL・名前・作者 | world.id / url / name / author | 場所の識別と基本情報 |
| 作者の説明・対応環境・定員 | world.description / platforms / capacity | 取得情報。感想とは分ける |
| 取得元・取得日時 | world.source / fetchedAt | 自動取得なら取得元と時刻を保存。手入力では確認日をメモで補える |
| 訪問日・訪問環境 | visitedAt / environment | 今回の体験の条件 |
| ひとことでいうと | notes.summary | 自分の要約 |
| 景色・空間 | notes.scenery | 見たこと・感じたこと |
| 音・音楽 | notes.sound | 実際に聞いたこと |
| できること | notes.activities | 体験したこと。作者説明だけならその旨を書く |
| よかったところ | notes.highlights | 個人の感想 |
| 気になったところ | notes.concerns | 個人の感想。なければ空欄 |
| おすすめ | notes.recommended | 自分が勧めたい用途や人 |
| 写真・説明 | photos / caption | メモと対応する写真 |
| 記事タイトル・本文 | title / body | 編集・添削後の文章 |
| レポートID・版 | id / revision | 一回の記録の識別と変更管理 |

自由記述のメモを一律の評価点や固定タグに変換する規格ではありません。「未確認」「非対応」「該当しない」を区別します。未確認の値は空文字・空配列・nullとして保存する項目があり、項目ごとに型が異なります。現段階では、アプリ間交換のための厳密なJSON Schemaは提供していません。

## バージョンと保存

人が記入するテンプレートの版は **v0.1**、アプリの内部保存形式は **schemaVersion: 1**。これらは別のバージョンです。今回のアプリ配布版は **v0.1.2** です。

SQLiteが原本です。Codexにはinput.json・request.md・写真を渡し、article.mdを取り込みます。review.jsonとedited.mdは保存内容の控えです。内部JSONを直接編集してもSQLには反映しません。既存の個人データやAPIキーはGitHubへ公開しません。

ツールの紹介記事など、訪問を伴わない記事はkind: articleとして取り込み、ワールド情報を捏造せずに保存・投稿します。通常の記録はkind: world-reviewです。kindがない旧データはworld-reviewとして読み込みます。
